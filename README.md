## 📖 Descrição do Projeto
Este código foi desenvolvido durante as aulas da disciplina com o Prof. Denisson e tem como objetivo organizar e exibir informações em formato de tabela utilizando HTML. O projeto resolve a necessidade de estruturar dados de maneira visual e organizada em uma página web. Foram aplicados conceitos fundamentais de desenvolvimento web, como estruturação HTML, uso de tabelas, tags semânticas e organização de conteúdo. Além disso, o exercício contribuiu para a prática da lógica de organização e formatação de elementos em páginas web.
## ▶ Como Executar
# ▶ Como Executar

1. Abra a pasta do projeto no Visual Studio Code.
2. Acesse a pasta `src`, onde estão os arquivos do projeto.
3. Abra o arquivo `index.html` em qualquer navegador de internet.
4. O navegador exibirá a página contendo a tabela e os elementos desenvolvidos durante a atividade.
5. Caso utilize a extensão Live Server no VS Code, basta clicar em “Go Live” para executar o projeto localmente.
